## 📖 Project Template

When adding new projects, I use this template structure:

```
project-name/
├── README.md           # Project documentation
├── src/               # Source code (.cpp, .h, .py files)
├── include/           # Header files (C/C++ projects)
├── tests/             # Test files
├── build/             # Build output (C/C++ projects)
├── docs/              # Additional documentation
├── CMakeLists.txt     # CMake build file (C/C++ projects)
├── Makefile           # Alternative build file (C/C++ projects)
├── requirements.txt   # Dependencies (Python projects)
└── .gitignore        # Git ignore file
```

### Project README Template

Each project includes:

- **Description**: What the project does
- **Technologies Used**: Languages, frameworks, tools
- **Features**: Key functionality
- **Installation**: Setup and compilation instructions
- **Usage**: How to compile and run the project
- **Build Instructions**: CMake/Make commands (C/C++) or Python setup
- **Screenshots**: Visual demonstration (if applicable)
- **Lessons Learned**: Key takeaways and challenges
- **Future Improvements**: Planned enhancements

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/leroykhoo/PersonalProjects.git
   cd PersonalProjects
   ```

2. **Navigate to a specific project**

   ```bash
   cd project-name
   ```

3. **Follow the project-specific README for setup and build instructions**

## 🔨 Building Projects

### C/C++ Projects

```bash
# Using CMake
mkdir build && cd build
cmake ..
make

# Using Make directly
make

# Running the executable
./project-name
```

### Python Projects

```bash
# Install dependencies
pip install -r requirements.txt

# Run the project
python main.py
```
